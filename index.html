Connect your Google Sheet once — data will sync automatically on every device after that.
1
Create a Google Sheet
Go to sheets.google.com → create a new blank spreadsheet.
2
Add the Apps Script
Extensions → Apps Script → delete existing code → paste the entire Code.gs file → paste your Sheet ID into the SHEET_ID variable → Save.
3
Deploy as Web App
Deploy → New deployment → Web app → Execute as: Me → Access: Anyone → Deploy → Authorize → copy the URL.
4
Paste Web App URL here
Your data lives entirely in your own Google Sheet — nothing is sent anywhere else.
